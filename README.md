# git

个人 Git 仓库，用于存放日常练习与项目代码。

## 仓库信息

- 远程地址：<https://github.com/LuciusGE/git>
- 默认分支：`main`
- 可见性：公开（Public）

## 快速开始

```bash
git clone https://github.com/LuciusGE/git.git
cd git
```

## 常用命令

```bash
git status              # 查看工作区状态
git add <file>          # 暂存改动
git commit -m "说明"     # 提交改动
git push                # 推送到远程
```
